# Game Off 2026: Shift

A Unity game developed for GitHub Game Off 2026, exploring the theme "Shift."

## Requirements

- Unity Hub
- Unity **6000.3.10f1**, as recorded in [ProjectVersion.txt](ProjectSettings/ProjectVersion.txt)
- Git and Git LFS

## Getting started

Install Git LFS before cloning the repository:

```bash
git lfs install
git clone https://github.com/YYchainsAw/unity-shift-jam.git
cd unity-shift-jam
git lfs pull
```

In Unity Hub, select **Add project from disk**, choose the cloned folder, and open it with the Unity version listed above.

## Team workflow

- Create a branch from the latest `main` for each task.
- Open a pull request into `main` and request a review from the project maintainer.
- Use English for documentation, issues, pull requests, and commit messages.
- Commit Unity assets together with their `.meta` files.
- Images, source artwork, and audio formats listed in [.gitattributes](.gitattributes) are managed with Git LFS.

See [CONTRIBUTING.md](CONTRIBUTING.md) for branch names, commit examples, and verification guidelines.
